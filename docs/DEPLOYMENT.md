# Deploying to Hostinger VPS (Ubuntu)

Needs a **VPS** plan (KVM 2 recommended) — shared hosting can't run Node/Python daemons.
Replace `example.com` with the real domain throughout.

## 1. Server packages (once)

```bash
apt update && apt upgrade -y
apt install -y git python3 python3-venv python3-pip nginx certbot python3-certbot-nginx postgresql postgresql-contrib
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt install -y nodejs
npm install -g pm2
```

## 2. Database (once)

```bash
sudo -u postgres psql
CREATE USER fortune WITH ENCRYPTED PASSWORD 'strong-password';
CREATE DATABASE fortune_decor OWNER fortune;
\q
```

## 3. Code + setup

```bash
mkdir -p /var/www && cd /var/www
git clone <repo-url> fortunedecor && cd fortunedecor
chmod +x scripts/*.sh
./scripts/script.sh --prod        # creates venv, env files, installs deps, migrates + seeds the DB
```

Edit the generated env files before the first `run.sh prod` (NEXT_PUBLIC_* vars are baked in at build time):

| File                     | Set |
|--------------------------|-----|
| `backend/.env`           | `APP_ENV=production`, `DATABASE_URL=postgresql+psycopg://fortune:strong-password@localhost:5432/fortune_decor`, `CORS_ORIGINS=https://example.com,https://www.example.com`, `ADMIN_CORS_ORIGINS=https://admin.example.com`, `SITE_URL=https://example.com`, `CMS_URL=https://admin.example.com`, `SMTP_*` + `ENQUIRY_NOTIFY_TO` for enquiry emails. `SECRET_KEY` and `REVALIDATE_SECRET` are generated by setup (the API refuses to start in production with a weak `SECRET_KEY`). |
| `frontend/.env.local`    | `NEXT_PUBLIC_API_URL=https://api.example.com`, `API_INTERNAL_URL=http://127.0.0.1:8000`, `NEXT_PUBLIC_SITE_URL=https://example.com` (`REVALIDATE_SECRET` is copied from `backend/.env` by setup) |
| `cms/.env.local`         | `NEXT_PUBLIC_ADMIN_API_URL=https://admin-api.example.com`, `NEXT_PUBLIC_SITE_URL=https://example.com` |

```bash
cd backend && ./venv/bin/python -m app.cli create-admin --email you@example.com && cd ..
./scripts/run.sh prod        # migrate + seed, start APIs, build website + CMS against them, start all under PM2
pm2 startup                                                   # run the command it prints (auto-start on reboot)
```

## 4. DNS (Hostinger hPanel → Domains → DNS)

A records → VPS IP: `@`, `www`, `api`, `admin`, `admin-api`.

## 5. Nginx + SSL

```bash
sed -i 's/example\.com/yourdomain.com/g' deploy/nginx/fortunedecor.conf
cp deploy/nginx/fortunedecor.conf /etc/nginx/sites-available/fortunedecor
ln -s /etc/nginx/sites-available/fortunedecor /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
certbot --nginx -d yourdomain.com -d www.yourdomain.com -d admin.yourdomain.com -d api.yourdomain.com -d admin-api.yourdomain.com
```

If the project is not in `/var/www/fortunedecor`, fix the `/uploads/` alias path in the Nginx file.

## 6. Updating

```bash
cd /var/www/fortunedecor && git pull
./scripts/script.sh --prod
./scripts/run.sh prod
```

## Useful

```bash
./scripts/run.sh status | logs | stop
ufw allow OpenSSH && ufw allow 'Nginx Full' && ufw enable    # only 22/80/443 exposed; app ports bind to 127.0.0.1
```
